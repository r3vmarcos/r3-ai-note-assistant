# Atualização v4.2.2

Esta versão adiciona as opções `Livre` para objetivo do conteúdo e perfil de escrita.

No objetivo `Livre`, o plugin não força uma finalidade fixa para o texto.
No perfil `Livre`, o plugin não força estilo, tom ou estrutura padrão.

A intenção é deixar a IA decidir com mais liberdade a direção, profundidade e formato da resposta, reduzindo padronização excessiva.
